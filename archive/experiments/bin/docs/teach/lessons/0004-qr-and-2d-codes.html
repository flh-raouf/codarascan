Lesson 4

QR And 2D Codes

QR codes are barcodes in the broad sense, but their detector should not be the same as a 1D detector.

Page 21 contains many 1D labels and a 2D code near the lower right. That should be a separate branch.

The distinction

  • 1D: data changes along one scan direction. Parallel-bar texture is the clue.
  • QR: square modules plus finder patterns. The clue is geometry and grid structure.
  • Data Matrix: grid modules plus an L-shaped finder border and alternating timing border.
  • PDF417: stacked rows, half-way between linear and matrix thinking.

Retrieval check

Why not use one single visual rule for 1D and QR codes?

  1. Their reliable visual anchors differ.
  2. Their file extensions are different.

Primary source: OpenCV's QRCodeDetector docs expose QR-specific detection and decode methods.
