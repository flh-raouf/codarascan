# Codara lineage notes

Codara was the application checkout where the post-version-8 engines continued to evolve. That checkout is not part of this repository, so no synthetic standalone Codara package is created here.

The reviewable adapter snapshot is under [`src/barcode_detection/integrations/codara`](../../src/barcode_detection/integrations/codara/README.md). This directory is reserved for future migration notes, commit references, and dependency manifests that explain how a Codara release maps back to this repository.
