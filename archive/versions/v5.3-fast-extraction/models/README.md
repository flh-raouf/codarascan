# v5.3 fast-locator models

The historical v5.3 experiment evaluated compact learned locator artifacts.
They are not used by the active `codarascan` package and are intentionally not
distributed because their complete training-data and redistribution provenance
is unavailable.

The experiment source is retained. Locally regenerated checkpoints belong in
this ignored directory and must be trained only from data you are authorized to
use.
