Lesson 8

False Positive Rejection

The detector's first pass should over-detect. Filters make it useful.

Page 21 is the stress test: rotated labels, tables, text, and a 2D code in one page.

Good filters

TestWhy it helps
Aspect ratio1D barcodes are usually wider than they are tall after rectification.
Transition countReal bars create many black-white changes along scan lines.
Fill ratioTables are thin; barcode regions are dense.
Quiet zoneText touching the candidate often breaks the blank margin.
Duplicate mergeMulti-angle search sees the same symbol more than once.

Design habit

Every filter should answer one visual question. Avoid a magic score until you can name what each component rejects.
