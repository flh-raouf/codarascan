Lesson 11

Evaluate Like An Engineer

The detector is good only if measured against expected boxes.

Make a tiny ground truth

For 21 pages, manual labels are realistic. Store each expected barcode as a 4-point polygon. Then compare predicted boxes against ground truth with IoU.

MetricMeaning
True positivePredicted box overlaps a real barcode enough.
False positivePredicted box is not a barcode.
False negativeReal barcode was missed.
PrecisionOf predicted boxes, how many were real?
RecallOf real barcodes, how many were found?

Best failure report

Do not just say "missed page 21." Say "missed two 30-degree labels touching table lines." That tells us which filter or angle to fix.

Retrieval check

A detector finds few boxes, all correct, but misses many real labels. What is low?

  1. Recall.
  2. Filename.
