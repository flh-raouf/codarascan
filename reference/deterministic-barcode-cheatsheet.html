Deterministic Barcode Detection Cheat Sheet

1D Barcode Signal

  • Many parallel dark bars with high local contrast.
  • Many black-white transitions across the bar direction.
  • Strong gradient coherence: edges point in similar directions.
  • Usually rectangular, with a quiet zone around the symbol.

Basic Pipeline

render page at 200-300 DPI
grayscale
for angle in candidate_angles:
    rotate page
    emphasize bars with gradient or blackhat
    threshold
    morphology close to merge bars
    find contours
    filter geometry and texture
    map boxes back to original page
merge duplicates with NMS
draw boxes and save JSON
