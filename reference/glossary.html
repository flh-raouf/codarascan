Barcode Glossary

Terms we will reuse across the course.

TermMeaning
1D barcodeA symbol made of parallel bars and spaces. Data is recovered by scanning across the bars.
2D codeA symbol whose data is stored in a two-dimensional grid or stacked structure, such as QR, Data Matrix, Aztec, or PDF417.
ModuleThe smallest nominal unit of a barcode. Bars and spaces are built from one or more modules.
Quiet zoneBlank margin around the code. Decoders need it to know where the symbol starts and ends.
SymbologyThe barcode format and rules, such as Code 128, Code 39, EAN-13, QR Code, or Data Matrix.
LocalizationFinding the code region in an image and returning its box or polygon.
DecodingReading the located symbol and converting the visual pattern into data.
Projection profileA 1D summary made by summing dark pixels along rows or columns.
MorphologyImage operations such as erosion, dilation, opening, and closing, usually applied to binary images.
ContourA connected outline around a foreground region.
IoUIntersection over Union, a score for how much a predicted box overlaps a ground-truth box.
