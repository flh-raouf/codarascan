Lesson 10

Build The Dossier Detector

A practical detector is a page loop, a candidate extractor, filters, and debug output.

Keep the first version small

input: rendered page PNGs
for each page:
    candidates = []
    for angle in [0, 15, -15, 30, -30, 45, -45, 90, -90]:
        candidates += detect_1d_barcodes(rotated_page)
    boxes = merge_duplicates(candidates)
    save boxes to detections.json
    draw boxes to output/pages/page-XX.png

Minimum output

  • detections.json with page number, box points, angle, and score.
  • One annotated image per page.
  • Optional crops only after boxes look plausible.

Retrieval check

Why save annotated debug images?

  1. They make JSON prettier.
  2. They expose detector mistakes.
