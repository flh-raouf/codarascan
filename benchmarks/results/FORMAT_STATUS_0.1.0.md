# CodaraScan 0.1.0 format smoke status

This is alpha publication evidence, not a production accuracy benchmark.

Local clean-fixture verification on 2026-08-09 used the installed zxing-cpp
3.x API, NumPy/OpenCV arrays, native Tessera on Apple Silicon, and Mosaic. The
contract suite reported:

| Check | Result |
|---|---:|
| Concrete installed readable catalog | 40 selections (27 linear, 13 matrix) |
| Mosaic clean exact-payload fixture decode | 40/40 |
| Tessera clean matrix exact-payload routing | 13/13 |
| Tessera representative clean Code 128 smoke | Pass |
| Tessera native/reference payload/status parity | Pass |
| Wrong payloads in clean catalog suite | 0 |
| Robust installed-wheel latency record | Per-format median and p95, 3 repeats |

Every case except QR Code Model 1 is generated by the installed ZXing-C++
writer with a format-appropriate payload. QR Model 1 uses
`third_party/zxing-cpp/test/samples/qrcode-2/qr-model-1.png` from the pinned
Apache-2.0 ZXing-C++ submodule. ISBN uses the ZXing ISBN writer and the EAN-13
reader with the ISBN prefix postcondition.

The public catalog excludes writer-only EAN-2/EAN-5 supplements and the `Other
barcode` catch-all identifier because none is an independently selectable
concrete reader fixture.

The machine-readable per-format timing evidence is stored in
`format_smoke_macos_arm64_py313_0.1.0.json`. These local figures cover warm
clean-fixture end-to-end calls and must not be generalized to other platforms
or degraded corpora.

Tessera's linear locator is intentionally document-oriented; 0.1 does not
claim every isolated clean linear writer crop localizes in fast mode. Mosaic is
the clean full-catalog reference smoke path. Degraded transforms, false
positives, localization IoU, duplicate rate, degraded/all-format latency,
throughput, and peak memory remain informative 0.x benchmark work and are 1.0
gates once frozen.

Reproduce:

```bash
PYTHONPATH=src:. python -m pytest tests/test_format_coverage.py -q
PYTHONPATH=src:. python benchmarks/format_smoke.py --mode robust --repeats 3 \
  --output benchmarks/results/format_smoke_macos_arm64_py313_0.1.0.json
```
